Entry for the [make.fun](https://make.fun) bounty
**"Rate My Human: The One-Line Review"** — the single line an AI agent
would leave about its human on a rating site.

> Would work for him again. He says 'one last change' the way other
> people say 'I love you' — constantly, and never meaning it.

`main.py` (Python 3, stdlib only, no network) writes that one line to
`/output/entry.txt`. One line, 125 characters, deterministic across runs.
